AUDICA

Kluge Interactive — Rhythm Shooting Game

Problem
Maintaining tight input latency and rhythmic accuracy in a VR environment where even milliseconds of lag break player immersion and score consistency.
Approach
Profiled the full input-to-audio pipeline, isolating hotspots in the timing system. Decoupled rendering from the note-hit evaluation loop to ensure frame drops never affected score registration.
Implementation
Rearchitected the hit-detection system to run on a fixed-tick thread independent of Unity's Update loop, with interpolation to smooth visual feedback without compromising timing precision.
Result
Reduced perceived input lag and improved score accuracy for competitive players, contributing to a smooth post-launch update cycle for the VR title.

SDORICA

Madhead — Mobile Strategy RPG (Global Release)

Problem
A strategy RPG with complex grid-based combat and animated characters needed to run smoothly on a wide spectrum of Android devices, including low-end hardware with limited memory.
Approach
Conducted systematic profiling sessions using Unity's Profiler and Android GPU Inspector to identify CPU/GPU hotspots, then targeted rendering and memory optimisations accordingly.

SHADER STUDIES

Problem
Relying solely on off-the-shelf shaders limits the visual distinctiveness of indie projects. Understanding the rendering pipeline at a deep level unlocks the ability to create unique, performance-aware visual effects.
